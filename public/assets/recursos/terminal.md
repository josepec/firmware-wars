# Terminal Imprimible

El Terminal es la ficha de juego donde cada jugador programa las acciones de su Bot durante la fase `RUNTIME()`. Está diseñado para imprimir, recortar y usar en partida.

Cada Terminal incluye las ranuras de ejecución, el espacio para las variables del Bot y los indicadores de versión.
